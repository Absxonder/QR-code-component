# QR Code Component

A simple QR code component built with HTML and CSS as part of a Frontend Mentor challenge.

## Technologies Used

- HTML5
- CSS3

## Features

- Responsive QR code card
- Centered layout
- Styled typography
- Rounded corners
- Proper spacing and sizing

## Live Demo

https://absxonder.github.io/QR-code-component/

## Project Preview

A simple QR code card that users can scan to visit Frontend Mentor.

- Styling elements with CSS
- Working with margins and padding
- Controlling element width and height
- Styling images
